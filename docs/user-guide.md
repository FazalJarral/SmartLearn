# User Guide

## Guest Study Session

Open SmartLearn, choose a text-based PDF, and submit it from the upload screen. Guests can process one accepted upload per UTC day. Guest results are temporary, so registered accounts are recommended for persistent history.

## Registered Learner

Create an account or sign in with Supabase Auth. From the dashboard, upload a PDF, track processing progress, and revisit completed packages from history.

## Learning Package

Use Summary for key points and simple definitions, Topics for a complete topic list and further-learning searches, Flashcards for recall, Quiz for scored practice, and Video for the animated Manim explainer. MP4 playback and download appear when rendering succeeds.

## Deletion

Deleting a package requires confirmation and removes related database records and private storage objects.
